One funny line a hopeless tech support agent says to a desperate customer,
entered in the Make.fun bounty "Have You Tried Turning It Off?".

The program in `main.ts` writes the line to `/output/entry.txt`.
It checks the line is between 1 and 200 characters first, so the
bounty's gate always sees a valid entry.

The line:

> Have you tried turning it off and on again? Good. Now turn off the
> computer, the router, and your hope of a different answer.

Run it with `node main.ts`. Set `MAKEFUN_OUTPUT_DIR` to choose where
`entry.txt` is written; it defaults to `/output`.
